Programming Quests

The game already works. These quests start with number changes, then move into objects, functions, conditionals, timers, and simple AI.

  1. Tune the feel: open `js/student-challenges.js` and change `maxRunSpeed`, `jumpVelocity`, or `gravity`.
  2. Swap players: change `activePlayerType` to `comet` or `boulder`, then compare the profiles in `playerTypes`.
  3. Invent a player: add a new entry to `playerTypes`, choose a sprite, and give it a trade-off.
  4. Change movement code: edit `updatePlayer` to add a glide, dash, or slippery stopping rule.
  5. Place smarter enemies: use the Designer enemy brushes, then change `enemyPattern` or the enemy objects in `enemyTypes`.
  6. Write enemy AI: add a new enemy type with an `update` function that uses timers, distance, or direction.
  7. Invent a rule: change `onCoinCollected`, `canUseGoal`, or `onPowerUpCollected` so levels reward a different strategy.
  8. Retheme the world: change `customization` to rename characters, assets, messages, the game title, background colors, or music.

Best Way To Work Together

Let the child drive the creative choices. Keep code sessions short, test after every small change, and use the designer whenever level changes would be tedious in code.
