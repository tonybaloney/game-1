Programming Quests

The game already works. These quests are small changes that teach useful programming ideas without making you build the whole engine first.

  1. Tune the feel: open `js/student-challenges.js` and change `maxRunSpeed`, `jumpVelocity`, or `gravity`.
  2. Add double jump: change `airJumps` from `0` to `1`, then try a harder level.
  3. Make coins matter: change `coinValue`, then make a level full of coins.
  4. Lock the goal: set `requireAllCoinsForGoal` to `true` so players must collect every coin.
  5. Change enemy behavior: edit `enemyPatrolSpeed` and test whether enemies feel fair.
  6. Invent a rule: add a new object in the designer, then write what it should do before coding it.

Best Way To Work Together

Let the child drive the creative choices. Keep code sessions short, test after every small change, and use the designer whenever level changes would be tedious in code.
